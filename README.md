# CSPSigner

[English](README.en.md)

CSPSigner - Windows-утилита для пакетного подписания файлов через **КриптоПро CSP**. Выберите документы и сертификат: программа создаст отдельную подпись **CAdES-BES** для каждого файла. Исходные байты остаются без изменений.

**[Скачать последний релиз](https://github.com/Alox1d/act-signer/releases/latest)** - полностью распакуйте `CSPSigner-VERSION.zip` и откройте `Start.cmd`.

## Примеры использования

- Подписать документы, таблицы, XML или архивы одним пакетом.
- Добавить свою подпись к файлу с существующей подписью другой стороны.
- Подготовить комплект исходных файлов и подписей для передачи или архива.

## Что нужно

- Windows с рабочим столом и встроенным **Windows PowerShell 5.1**. `Start.cmd` выбирает нужную среду.
- Установленные **КриптоПро CSP**, локальные компоненты **CAdESCOM** и доступный Windows Script Host (`cscript.exe`). [Загрузка компонентов КриптоПро](https://www.cryptopro.ru/products/cades/downloads).
- Действующий сертификат **ГОСТ Р 34.10-2012** и доступ к закрытому ключу. Для USB-токена нужен его драйвер.
- Чтение исходников и запись в папку результата. Размер одного файла - до **64 МиБ**.

В VM компоненты и ключ должны быть доступны внутри гостевой Windows. Python, Node.js и сборка проекта для запуска не нужны.

## Как подписать

1. Откройте **`Start.cmd`**.
2. Выберите размещение результата, сертификат и формат имени подписи. **Подробнее** показывает сведения о сертификате и диагностику.
3. Выберите исходную папку: поиск в ней и подпапках начнётся сразу. Вставленный путь подтвердите Enter. Для отдельных документов используйте **Выбрать файлы...**.
4. Проверьте список, отметьте нужные файлы и нажмите **Проверить и подписать**.
5. Введите PIN в штатном окне КриптоПро или токена и дождитесь итогов в консоли.

Если изменили папки, сертификат или формат имени после поиска, нажмите **Обновить список**. Повторное обновление того же списка сохраняет галочки и выборку отдельных файлов.

Ctrl/Shift выделяют группу строк; пробел меняет её галочки. Действия группы также есть в меню правой кнопки. **Выбрать все** и **Снять все** действуют на весь список.

Формат содержимого не ограничен: можно подписать PDF, DOCX, XLSX, XML, ZIP, изображения и другие файлы. При поиске папки пропускаются файлы подписей, `.tmp` и журналы программы. Их можно выбрать явно кнопкой **Выбрать файлы...**. Вложенная папка результата исключается из исходников. Архивы при поиске папки видны, но изначально без галочки. Их можно отметить вручную; явно выбранные архивы отмечаются сразу.

## Где будет результат

В новой установке подписи по умолчанию включают полное имя исходника:

```text
Документы/
  report.docx
  report.docx_ivanov.sig
  report.pdf
  report.pdf_ivanov.sig
```

Фамилия берётся из сертификата и переводится в латиницу. При её отсутствии используется метка `cert_<12 символов отпечатка>`. Несколько документов можно хранить в одной папке.

| Формат имени | Пример |
| --- | --- |
| Полное имя файла и фамилия, по умолчанию | `report.docx_ivanov.sig` |
| Только фамилия | `signature_ivanov.sig` |
| Имя без расширения и фамилия | `report_ivanov.sig` |
| Прежний формат | `report.my.sig` |

Для нескольких файлов в одной папке используйте формат по умолчанию: остальные варианты могут давать одинаковые целевые имена. Существующие файлы не перезаписываются.

В отдельной папке результата сохраняется структура подпапок, копируется выбранный исходник и подписи, математически подтверждённые для него. Другие вложения автоматически не копируются. Для проверки храните **исходный файл и соответствующий SIG** вместе. Визуальный штамп и встроенная подпись в документ не добавляются.

## Повторный запуск и проверка

CSPSigner проверяет соседние `.sig`, `.p7s`, `.p7m` и `.sgn` независимо от имён и сопоставляет их с точными байтами файлов.

- Подтверждённая подпись выбранным сертификатом даёт `already_signed`: новая подпись и копии не создаются, ключ не используется.
- Подтверждённая чужая подпись допускает добавление своей. Истёкший чужой сертификат сам по себе этому не мешает.
- Подпись другого файла исключается из проверки текущего только после успешной математической проверки на этом другом исходнике.
- Повреждённая или неопределённая подпись блокирует текущий файл; независимые файлы продолжают обрабатываться.
- Отмена криптографической операции или неисправный общий сеанс останавливает пакет. Сохранённые результаты остаются.

Каждая новая подпись проверяется КриптоПро перед сохранением. Математическая проверка существующих подписей не устанавливает доверие к сертификату и историческое время подписания. Доверенная метка времени и комплект для долгосрочной проверки не создаются.

## Настройки и обновления

Настройки хранятся в `%LOCALAPPDATA%\CSPSigner\settings.json`. При первом запуске предпочтения ActSigner переносятся автоматически, включая прежний формат имени. CSV-журналы находятся в `<папка результата>\_CSPSigner_logs`.

`Start.cmd` проверяет стабильные релизы GitHub в фоне. Проверенное обновление включается при следующем запуске. Для совместимости с установленными версиями сохранены прежние внутренние имена модулей, адрес репозитория и каталог обновлений `%LOCALAPPDATA%\ActSigner\updates`.

## Если что-то не работает

- Нет сертификата или ошибка КриптоПро: нажмите **Подробнее**, затем запустите `diagnostics\Check-CryptoPro.cmd`. [Инструкция диагностики](diagnostics/README.txt).
- Консоль ждёт: проверьте окно PIN через Alt+Tab. Если в заголовке есть **Выбрать / Select**, нажмите Esc.
- Для [сообщения об ошибке](https://github.com/Alox1d/act-signer/issues) укажите версию, этап и текст ошибки. Не прикладывайте ключи, PIN и рабочие документы.
